# jamesmadson.me

Personal site of James Madson, product design engineer in Seattle.

Built with [Eleventy](https://www.11ty.dev), hand-rolled Sass, and vanilla JavaScript. No frameworks, no CSS libraries. The how and why lives on the [colophon](https://jamesmadson.me/colophon/).

## Develop

```
npm install
npm run build:css && npm run build
npm run dev
```

Deploys to [jamesmadson.me](https://jamesmadson.me) from `master` via GitHub Actions.

The code is public to read. The design, writing, and imagery are © James Madson and not licensed for reuse.
