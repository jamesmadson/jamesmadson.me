How I work

Useful Clear Resonant Lasting

Useful first

If a thing isn't useful, nothing else about it matters much to me. Clear and built to last come right after.

Judgment over tools

Tools change every year and I try most of them. Deciding what's worth building doesn't change, and that's most of the job.

Prototype in code

I'd rather make a rough working version than a polished static one. You find out what's true a lot faster when it runs.

Honest early

When something isn't working I try to say so right away. It's cheaper than saying it in month three.
