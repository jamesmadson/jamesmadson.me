Prototype v2 · Figure system · NatureDose

One system, three fidelities

Case-study figures sourced from the NatureQuant Figma. Evidence is exported pixels, working figures are rebuilt in code, abstractions carry structure only. Set in Replica and Replica Mono where installed.

The system

  • Evidence is exported pixels, never redrawn. Big crop first, device second.
  • Working figures are rebuilt in code and labeled as rebuilt. One or two per study.
  • Abstractions are monochrome and carry structure only.
  • Panels are self-grounded like photographs. Page chrome follows the theme; figures keep their own light.
  • Type is Replica and Replica Mono, loaded locally for now. Web license before shipping.
  • Grain at 5%, one glow per panel, reduced motion honored, keyboard reachable.
